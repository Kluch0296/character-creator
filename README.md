# Создание персонажа DnD

Этот небольшой проект демонстрирует простой конфигурируемый веб‑сервис для создания персонажа первого уровня в DnD.

## Запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <URL-репозитория>
   cd character-creator
   ```
2. Запустите локальный веб‑сервер. Проще всего использовать встроенный сервер Python:
   ```bash
   python3 -m http.server 8000
   ```
   После запуска сервер будет доступен по адресу <http://localhost:8000/>.
3. Откройте браузер и перейдите по адресу `http://localhost:8000`. Появится страница выбора уровня, затем можно будет выбрать расу и подрасу. Выборы будут сохранены и отображены в виде JSON.

## Настройка

- Конфигурация страниц хранится в файле `config.json`. Можно добавлять новые страницы и опции, расширяя этот файл.
- Основная логика приложения находится в `script.js`, стили — в `style.css`.

В конфигурации доступны следующие типы страниц:

* `buttons` — выбор с помощью кнопок (один вариант);
* `text` — поле для ввода произвольного текста;
* `radio` — набор радиокнопок (единственный выбор);
* `checkbox` — список чекбоксов (можно выбрать несколько).

Страница может содержать несколько элементов одновременно. Для этого вместо поля
`type` задайте массив `elements`, в котором перечислены блоки с собственными
`id`, `type` и другими параметрами. Пример смотрите в последнем разделе
`config.json`.

Для каждой опции можно указать поле `image` с путём к картинке. Изображение отобразится перед текстом кнопки или подписью опции.
