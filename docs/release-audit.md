# Проверка выпуска · 27 сентября 2026

## Сверка пошагового процесса

Прочитаны три независимых варианта инструкции:

1. [Wizards / D&D Beyond: Step-by-Step Characters, Basic Rules 2014](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/step-by-step-characters).
2. [Quest Portal: How to Create a D&D Character — 2014 5e Guide](https://www.questportal.com/blog/how-to-create-characters-in-d%26d).
3. [RPGBOT: How to Play DnD 5e](https://rpgbot.net/dnd5/how-to-play/).

Инструкции использованы как контрольный список этапов. Спорные механические зависимости проверяются по правилам соответствующей книги и errata, а не по советам по оптимизации. Правила 2024 не смешиваются с каталогом 2014.

| Область | Что проверяет приложение |
|---|---|
| Происхождение | Класс, раса, обязательная подраса, предыстория, конкретная версия расы |
| Характеристики | Стандартный набор, 27 очков либо ввод бросков; отдельно расовые и выбранные бонусы черт |
| Уровень 1 | Хиты, кость хитов, спасброски, бонус владения +2; подкласс, если он выбирается на первом уровне |
| Владения | Фиксированные выдачи от всех источников, отдельные ограниченные выборы, одноимённые дубликаты и замены того же типа |
| Компетентность | Только уже полученные владения; удвоение бонуса без повторного сложения |
| Бой | Стартовый инвентарь, надетый доспех, щит, КД, атаки, скорость, расовая броня и ограничения полёта |
| Магия | Различие известных, подготовленных и записанных в книгу заклинаний; дополнительные доменные/расовые заклинания и магия черт |
| Образ | Имя, внешние данные, мировоззрение, характер, идеалы, привязанности, слабости и заметка |
| Завершение | Повторная проверка всех шагов; итоговые числа, снаряжение и особенности; JSON для Long Story Short |

### Почему владения идут последними

Сначала вычисляются гарантированные владения и все источники свободного выбора. Навыки класса остаются ограничены списком класса. Повторный фиксированный навык или инструмент создаёт отдельное право на замену того же типа. Это следует из [Basic Rules 2014: Personality and Background — Proficiencies](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/personality-and-background).

Смена раннего выбора не позволяет незаметно сохранить лишние владения. Неактивные слоты удаляются с сообщением; конфликтующие активные выборы остаются видимыми и требуют исправления. Перед экспортом повторно проверяется каждый шаг, а восстановленный черновик возвращается к первому незавершённому этапу.

### Границы каталога

Первый уровень, один класс, legacy-редакция 2014. Представлены 50 конкретных расовых версий, 13 классов и 14 предысторий текущего каталога. Подклассы первого уровня, черты и основные списки заклинаний относятся к PHB 2014; изобретатель — к TCE. Не включены повышение уровня, мультикласс, произвольные домашние правила, создание собственной предыстории и замены классовых особенностей из Tasha's. Наличие расы из дополнения не означает включение всех подклассов этого дополнения.

### Проверки

- `npm run check`: синтаксис всех модулей и 65 успешно пройденных регрессионных тестов.
- Табличные тесты: 11 648 сочетаний рас/подрас, классов и предысторий текущего каталога.
- Живой браузер: плут-табакси-преступник, две замены совпавших владений, четыре навыка класса и две компетентности; карточка с ЛОВ 17, 10 хитами и КД 14.
- Живой браузер: вариантный человек — жрец Знания — мудрец с чертой «Умелый»: 10 навыков, две компетентности, шесть языков, 10 хитов и КД 17. После снижения Мудрости с 16 до 15 подготовка сократилась с четырёх до трёх заклинаний с пояснением; доменные заклинания сохранились отдельно.
- Импорт Long Story Short: см. отдельный [отчёт о формате](lss-format.md). При первом живом импорте обнаружено отличие в интерпретации бонуса оружия, поэтому одной проверки структуры JSON недостаточно.
